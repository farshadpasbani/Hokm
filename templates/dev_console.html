Overview

Agents use NFSP (Neural Fictitious Self-Play): a Q-network for best-response moves and an average-policy network trained by supervised learning on self-play. The default reward is outcome-aligned (terminal win bonus + trick differential), and evaluation runs with ε = η = 0 so the AI you measure is the same AI that plays humans.

              Training loss + |Q*| + Q-advantage (rolling mean, log scale)
              window 200
            

            

              Q-loss = Huber TD error; SL-loss = avg-policy cross-entropy;
              |Q*| (long-dashed) = mean absolute Q-target magnitude (divergence canary —
              should stay bounded);
              Q-advantage (short-dashed) = mean (max-Q − min-Q) over legal next-actions
              (discrimination canary — should climb as the agent learns which cards
              are better than others; staying near 0 means the policy is essentially
              uniform over legal cards).
            

            

          

          

            
Gradient steps per game

            

              Number of optimizer steps the shared learner ran each game. Should rise quickly to a steady plateau as the replay
              buffer fills. If this stays at 0, no learning is happening.

Evaluate against baselines

        

          

            Seats the trained checkpoint on Team 1 (seats 0 and 2) and fills Team 2 with the selected opponents.
            Reports win rate with a Wilson 95% CI, tie rate, and mean trick differential — the canonical “is this model strong?” signal.

Bulk simulation (CSV)

        

          
For per-trick CSV review logs (all AI), run from the project root:

          
python simulate_ai_games.py --games 100 -o game_logs/trick_review.csv

          
Or run the full baseline evaluation CLI:

          
python evaluate.py --checkpoint models/nfsp_shared_<...>.pth --opponent all --games 1000 --seed 42 \
    --out dev_cache/eval_suite.json --csv dev_cache/eval_suite.csv
